# Belentani - The Judas Experience

## Descripción
Belentani es una experiencia digital inmersiva y cyberpunk que explora el juicio de Judás a través de una narrativa interactiva, música electrónica y simulaciones de hacking de datos.

## Visión del Proyecto
Crear una plataforma digital única que fusione arte, tecnología y narrativa para explorar temas profundos de traición, redención y juicio en un contexto futurista.

## Componentes Principales
- **Narrativa Interactiva**: Exploración del juicio de Judás
- **Música Electrónica**: Soundscapes y composiciones originales
- **Simulaciones Cyberpunk**: Experiencias de hacking y data exploration
- **AI Lab**: Integración de inteligencia artificial generativa
- **Studio**: Herramientas creativas para usuarios
- **Galaxy**: Universo expandido del proyecto

## Tecnología
- **Frontend**: React.js, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Base de datos**: PostgreSQL/MongoDB
- **Audio**: Web Audio API
- **IA**: Integración con APIs de IA
- **Despliegue**: Base44, BuildAI.space
